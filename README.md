## 这是什么

一个面向在职成人远程学习者的算法探究型学习工具。它不是"会动的 PPT"，而是**可自测、可对比、可诊断**的实验台：

- **看得见过程** —— 逐帧动画，可暂停在任意一帧反复观察，而不是只给"第 i 趟排序结果"
- **看得见差别** —— 多算法同屏竞速，把 O(n²) 与 O(n log n) 的增长率差异变成肉眼可见的速度差
- **对得上代码** —— 伪代码行与动画帧双向绑定，动画走到哪一行就高亮哪一行
- **能自己动手** —— 调参数复现实验、亲手排一遍对账、先预判再验证
- **知道错在哪** —— 按错因标签聚类，定位到具体的概念混淆点

## 工程说明

- **渲染内核零框架**：`src/core`（算法与帧模型）+ `src/render`（Canvas 2D）为纯 TypeScript，
  禁止 `import react`，由 `scripts/check-boundary.mjs` 在构建前强制拦截
- **高频帧绕开 React**：算法每一帧都变，若走 React 状态会拖垮动画；
  画布由命令式代码独占重绘
- **状态接缝**：内核 Observable 快照 + `useSyncExternalStore`，是全项目唯一的跨层通道
- **零后端**：纯静态托管，无服务端逻辑
- **离线可用**：另有单文件形态，双击即可打开，无需服务器、无需联网
